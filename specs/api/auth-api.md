# API de autenticación

Plantilla para definir los contratos HTTP de autenticación.

Operaciones pendientes: login, refresh, logout, usuario autenticado actual, cambio de contraseña y revocación de sesión.

Para cada operación debe definirse: ruta, método, autenticación, request, response, errores y efectos secundarios. No se fijan payloads definitivos todavía.

Referencia: [identidad](../domains/identity.md) y [convenciones](../core/api-conventions.md).
