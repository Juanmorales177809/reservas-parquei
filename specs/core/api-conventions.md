# Convenciones de API

Plantilla para definir las convenciones HTTP comunes de la API, sin endpoints concretos.

Pendiente definir:

- prefijo y versionado;
- formato de fechas y horas;
- zona horaria;
- autenticación Bearer;
- paginación, filtros y ordenamiento;
- códigos HTTP;
- formato general de respuestas.

Referencias: [errores](errors.md), [identidad](../domains/identity.md) y contratos de API.
