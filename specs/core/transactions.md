# Transacciones y concurrencia

Plantilla para definir las garantías transaccionales y de concurrencia del sistema.

Pendiente definir:

- operaciones que requieren transacción;

- rollback;
- consistencia entre reservas, recursos, auditoría y notificaciones.

No contiene SQL ni código. Referencias: [reservas](../domains/bookings.md) y [modelo de datos](data-model.md).
