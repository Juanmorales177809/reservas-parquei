# Contratos CRUD

Plantilla para definir las operaciones internas de persistencia.

Pendiente definir consultas por ID, listados, creación, actualización, búsqueda de conflictos, asociaciones, operaciones permitidas por entidad y borrado lógico frente a físico.

Las operaciones de negocio como aprobar o rechazar pertenecen a la capa de servicios y no deben duplicarse aquí.
