# API de investigación

Plantilla para definir endpoints de consulta y gestión del contexto investigativo.

Pendiente definir operaciones para perfiles, modalidades de vinculación y relaciones con usuarios. Debe incluirse una operación administrativa para importar proyectos y semilleros mediante Excel, con validación previa, confirmación explícita y resultado por fila conforme a RN-IMP.

Referencia: [contexto investigativo](../domains/research-context.md).
